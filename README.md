# Organize Me

Application React d’organisation personnelle.

## Installation

```bash
npm install
```

## Lancer le projet en développement

```bash
npm run dev
```

## Construire pour la production

```bash
npm run build
```

## Structure principale

- `public/` : fichiers publics et configuration PWA
- `src/api/` : appels vers les services externes
- `src/components/` : composants React
- `src/entities/` : structures des données
- `src/hooks/` : hooks React personnalisés
- `src/lib/` : bibliothèques et services internes
- `src/pages/` : pages de l’application
- `src/utils/` : fonctions utilitaires
- `config.jsonc` : configuration générale
